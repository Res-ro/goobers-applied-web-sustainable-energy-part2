## 🤖 AI Feature: EOI Summary
This project uses AI to generate a short summary of EOI (Expression of Interest) data.

### 🔍 What it does
- Collects key data from the database (status, locations, skills)
- Sends this data to an AI model (LLaMA 3 via the Hugging Face API)
- Receives a short 3-sentence summary

### ⚙️ How it works
- PHP gathers and formats the data
- cURL sends it to the AI API
- The response is shown on the management page

### 📌 Purpose
This feature helps quickly understand trends in the EOI data without reading every record.
